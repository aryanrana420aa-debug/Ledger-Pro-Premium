# LedgerPro — Premium Billing Dashboard

A front-end prototype for a private admin billing system.

## Demo login
Email: `admin@example.com`
Password: `Admin@123`

## Features
- Admin login gate
- Dashboard revenue metrics
- Customer management
- Invoice creation
- Dynamic UPI QR
- Paid/Pending tracking
- Invoice PDF download
- Local browser persistence
- Responsive premium UI

## Run
Open `index.html` in a browser.

## Important
This version stores data in browser localStorage. For a production private business system, replace the demo login/localStorage with real authentication and a hosted database (for example Supabase), and never put production admin credentials in frontend JavaScript.
